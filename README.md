# ゴッツンサッカー

**遊ぶ → https://ftkr12.github.io/gottsun/**

でっかい頭でヘディング！ ヘッドボール風のあたまサッカーを、4人で（2対2で）遊べるようにしたゲームです。
試合時間（60秒・90秒・2分・3分から選ぶ）が終わったとき、点が多いチームのかち。同点なら、先に1点とったほうがかちの「Vゴール」。

- ボタンは 左右・ジャンプ・キック・スーパー の4つ。キックはくつの前か頭のそばにボールがあるときに押すとシュート（頭に当たってもヘディングシュート）
- キックはボタンひとつのまま、押すときの向きでけり分け
  - 前（相手ゴールの方）＋キック … 低くて速いシュート
  - キックだけ … ふつうのシュート
  - 後ろ（自分のゴールの方）＋キック … 高いループ
  - ジャンプ中に前＋キック … たたきつけ
- 相手をキックするとダメージ。体力（名札の上のバー）がなくなると、数秒うごけなくなる。しばらくけられなければ体力はもどる
- 相手の頭の上にも乗れる。相手と同時にけると、ボールが真上にはね上がる。せり合いが続くと、ボールが少しランダムにはじける
- キャラクターは13人。体の大きさ・はやさ・ジャンプ・キック・重さがはっきりちがい、それぞれ必殺わざ（スーパー）を持つ

`index.html` 1ファイルだけで動きます（ライブラリなし・サーバーなし）。

## 遊びかた（モード）

- **ひとりで あそぶ** … CPUと1対1、またはCPUの味方と組んで2対2
- **この画面で みんなで** … 1台を囲んで最大4人。キーボード4組とゲームパッドが使えます。自分のキックボタンを押すと参加、◀▶でキャラ、ジャンプでチーム、キックでOK。全員OKでキックオフ
- **スマホを合言葉でつなぐ** … スマホ2〜4台を、合言葉を送り合って *じかに* つなぐ（ガタゴト列島鉄道・てんてこまいキッチンと同じ方式）

人数が足りないチームにはCPUが入って2対2にそろいます（「いる人だけ」にもできます）。

## ボタン

|  | 左・右 | ジャンプ | キック | スーパー |
|---|---|---|---|---|
| キーボード1 | A・D | W | S / スペース | E |
| キーボード2 | ←・→ | ↑ | ↓ | Enter / 右Shift |
| キーボード3 | F・H | T | G | Y |
| キーボード4 | J・L | I | K | O |
| ゲームパッド | 十字キー / スティック | A | X・B | Y・LB・RB |

ひとりで遊ぶときは、どのキーでも動かせます（Z キック・X スーパーも可）。スマホでは画面のボタン。一時停止は Esc か P（ゲームパッドはスタート）。

## 合言葉でつなぐ手順

1. 1台目が「1台目（さそう側）」を押して合言葉を作り、LINE などで相手に送る
2. 相手は「2台目以降（さそわれた側）」で合言葉を貼り、「返事の合言葉」を作って送り返す。送ったら、ゲームのページにもどって開いたまま待つ（1台目が貼ってから2分のあいだは、2台ともおたがいを呼び続けます）
3. 1台目が返事を貼って「つなぐ」→ つながったら「もう1人さそう」で次の人を同じ手順でさそう（最大4台）
4. 各自がキャラクターをえらび、1台目がチーム（⇄）や試合時間を決めて「キックオフ！」。試合は1台目が進行します

それぞれのスマホは自分の選手を自分で動かし（ボタンにすぐ反応します）、ボールの動きは1台目が決めて、1秒に30回みんなに送ります。WebRTC のデータチャンネルで直接つながるので、試合中の通信はどこのサーバーも経由しません（接続時に STUN サーバーだけ使います）。

### 注意

- `claude.ai` のページの中（アーティファクト）や、ファイルを直接開いた状態（`file://`）では、安全のため直接接続が止められているので、GitHub Pages など **https のアドレス** で開いてください
- LINE などのアプリ内ブラウザではなく、Safari / Chrome で開くとつながりやすいです
- 同じ Wi‑Fi だとつながりやすく、職場や学校のネットワークではつながらないことがあります
- 試合中に誰かのスマホがスリープしたり通信がとぎれたりすると、その選手はCPUが代わりにプレーします。スマホがもどれば自動でもどり、接続が切れてしまったときは、1台目の一時停止メニューの「合言葉で呼びもどす」から同じ席にもどれます

## GitHub Pages に置く

リポジトリに `index.html`（と空の `.nojekyll`）を置いて、Settings → Pages で公開するだけです。

## 開発

`src/` のファイルを `node build.js` で1つの `index.html` にまとめています。
ルール部分（`src/data.js`・`src/engine.js`・`src/ai.js`）は DOM を使っていないので、Node でそのまま CPU どうしの試合をシミュレーションできます。

```
node build.js
node test/sim.js 20 normal normal 2   # CPUどうし 2対2 を20試合
```
